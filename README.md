# 🍽️ Restaurant Sales Manager

Modern sales and customer management system for restaurants, built with a focus on simplicity and efficiency.

## 📋 Overview

Complete web application to manage:
- 📊 Daily sales tracking
- 👥 Customer database
- 📈 Reports and analytics
- 📥 Excel export for accounting

**Problem Solved:** Small and medium restaurants need affordable management systems without monthly SaaS fees ($50-200/month).

## ✨ Features

- ✅ Intuitive and easy-to-use interface
- ✅ Complete customer and sales management
- ✅ Data export to Excel
- ✅ No monthly subscription costs
- ✅ Customizable for specific needs
- ✅ Built with AI assistance (Claude + Cursor AI)

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Backend: JavaScript (Vanilla)
Database: LocalStorage (client-side)
Development: Claude + Cursor AI for accelerated development
- **Database:** [Your choice - SQLite, LocalStorage, etc.]
